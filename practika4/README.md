## Краткая характеристика решения

Построена контекстно-свободная грамматика языка операторов присваивания варианта 4. В правой части оператора находится арифметическое выражение с переменными `a`-`d`, обычными вещественными константами, унарным минусом, операциями `*`, `/`, `+`, `-` и скобками.

В проекте обычная вещественная константа записывается как одна или несколько цифр, точка и одна или несколько цифр: `0.5`, `12.34`, `100.0`. Экспоненциальная форма, например `1e2`, не входит в язык.

Итоговая грамматика находится в нормальной форме Хомского и проверена алгоритмом CYK на 12 цепочках: 7 корректных цепочек приняты, 5 некорректных отклонены.

## Основные файлы

- [`variant4_cnf.jff`](<./03 Полученная КСГ в НФХ/variant4_cnf.jff>) - модель грамматики для JFLAP 7.1;
- [`variant4_cnf.txt`](<./03 Полученная КСГ в НФХ/variant4_cnf.txt>) - грамматика в текстовом виде;
- [`variant4.py`](<./04 Перехваты экранов распознавания тестовых цепочек методом CYK/cyk_variant4.py>) - независимая проверка алгоритмом CYK;
- [`test_results.txt`](<./04 Перехваты экранов распознавания тестовых цепочек методом CYK/test_results.txt>) - результаты тестирования.

## Запуск проверки

```bash
python3 "04 Перехваты экранов распознавания тестовых цепочек методом CYK/variant4.py"
```

Для проверки в JFLAP откройте `03 Полученная КСГ в НФХ/variant4_cnf.jff`, затем выберите `Input -> CYK Parse`.
